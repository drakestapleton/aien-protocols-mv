# Contract gaps found while preparing the matmul_u32 packet

Each item is something the task asked to be frozen that the current sources do not define, or define in two
ways. Each needs owner acceptance before a fixture can exist. None was filled in by this packet. Sources
are cited as `file:line` in the tree this packet was written against (aien-protocols-mv main at the head
recorded in the run receipt).

| # | Gap | Evidence | Fixture status |
|---|---|---|---|
| G1 | No attempt identity, lease generation or epoch on the wire. MJR1 has only an `attempt` byte (1 to `max_attempts`); the AN0 profile fixes `max_attempts` 1 and retry NEVER, and replay is by `dag_digest` only. Epoch and attempt exist only in a receiver-local action record (`omega-mv seed/authority/action.om`, as read in `docs/orchestra/MICROJOB.md` O12), not in any MJB1, MJR1 or AN0B field. | SPEC.md 5; PROFILE.md "Worker admission" 8; `aienet0.rs` `build_document` | none: stale-attempt, lease and epoch cases cannot be written |
| G2 | No compiler, profile, OS or target-ABI binding, and no compiled-cache identity. MJR1 `source_hash` is "the program / `.om` source that ran" (SPEC 5); PROFILE.md fills it with the worker binary hash. A source digest alone therefore stands in for source, compiler, profile, target and options. The exercised worker binary is itself unbound to a source commit. | SPEC.md 5; PROFILE.md "Worker admission"; historical source-binding findings retained with the phase evidence | none: cache-mismatch cases cannot be written |
| G3 | Only three carrier frames exist (bundle, receipt, refusal text) in open-humanity, outside this repository.
